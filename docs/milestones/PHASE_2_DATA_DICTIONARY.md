# Phase 2: MongoDB Schema Data Dictionary

This data dictionary defines every field in the proposed MongoDB collections for **JobMarketDB**, documenting data types, provenance tiers (**SOURCE**, **NORMALIZED**, or **DERIVED / INFERRED**), provenance from the raw datasets, transformations, nullability, and planned utilization in application search, filtering, and analytics.

---

## 1. Provenance Classification Framework

Every field is explicitly tagged with one of three provenance tiers:
1. **SOURCE:** Directly present in the original dataset without alteration of meaning or structure.
2. **NORMALIZED:** Converted into a common, standardized representation without claiming it was originally present in exactly that form.
3. **DERIVED / INFERRED:** Calculated, estimated, or inferred from one or more source fields using heuristic rules or mathematical formulas.
